# Django Recipe Management System

## Project Overview
The Django Recipe Management System is a simple web application that allows users to manage recipe information through the Django Admin Panel.

## Features
- Add new recipes
- Store recipe names
- Store ingredients
- Store cooking instructions
- Manage recipes through Django Admin
- Store data using Django models and SQLite database

## Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS

## Django Model
The Recipe model contains the following fields:
- `name` – Recipe name
- `ingredients` – Ingredients required
- `instructions` – Cooking instructions
