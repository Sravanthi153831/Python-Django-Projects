# Django Robot Management System 🤖

A simple Robot Management System developed using Python and Django.

## 🚀 Project Description

This project allows users to manage robot details through the Django Admin Panel.

## 🛠️ Technologies Used

- Python
- Django
- SQLite
- Django Admin
- GitHub

## ✨ Features

- Create and manage Robot records
- Add robot details through Django Admin
- Store data in the database
- View and update robot information

## 📂 Project Setup

1. Install Django:

   pip install django

2. Run migrations:

   python manage.py makemigrations
   python manage.py migrate

3. Start the development server:

   python manage.py runserver

4. Open the Django Admin Panel:

   http://127.0.0.1:8000/admin/

## 📸 Project Output

The Robot was successfully added and saved through the Django Admin Panel.

## 🎯 Purpose

This project was created for Django practice and learning database management using Django models.
