# 🤖 Robot Management System

## 📌 Project Overview

Robot Management System is a Django-based web application
developed to manage robot details using CRUD operations.

Users can add, view, edit, update, and delete robot information
through a simple web interface.

## 🚀 Technologies Used

- Python
- Django
- HTML
- SQLite3

## ✨ Features

- Add New Robot
- View Robot List
- Edit Robot Details
- Update Robot Information
- Delete Robot
- Django Forms Integration
- Database Management

## 📂 Project Structure

| File / Folder | Description |
|---|---|
| migrations/ | Database migrations |
| templates/ | HTML templates |
| robot_list.html | Add and display robots |
| edit_robot.html | Edit robot details |
| delete_robot.html | Delete robot details |
| admin.py | Django admin configuration |
| apps.py | Application configuration |
| forms.py | Robot form handling |
| models.py | Robot database model |
| urls.py | URL routing |
| views.py | CRUD application logic |

## ⚙️ Installation and Setup

### Step 1: Clone Repository

git clone https://github.com/Sravanthi153831/Python-Django-Projects.git

### Step 2: Navigate to Project Folder

cd Python-Django-Projects/03-Django-Web-App/06-Django-Robot-CRUD-Project/Robot_project

### Step 3: Install Django

pip install django

### Step 4: Apply Migrations

python manage.py makemigrations

python manage.py migrate

### Step 5: Run Server

python manage.py runserver

### Step 6: Open Browser

http://127.0.0.1:8000/robots/
