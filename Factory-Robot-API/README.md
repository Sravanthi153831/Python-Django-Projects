# Robot Item Registration API 🤖

A REST API for registering robot items successfully.

## 🚀 Features

- Register a robot item
- Store robot item details
- Return success response after registration
- HTTP 201 Created response
- JSON API response

## 🛠️ Technologies Used

- Python
- Django
- Django REST Framework
- SQLite
- REST API

## 📌 API Response
**HTTP Status Code:** `201 Created` 
Example successful response:

```json
{
    "message": "Item registered by Robot successfully",
    "status": "success"
}
