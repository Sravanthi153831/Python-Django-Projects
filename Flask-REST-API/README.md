Flask REST API 
📌 Project Description 
This is a simple Flask REST API Project developed using  Python and SQLite.The API allows users to create and manage tasks.
🚀 Features
• Create a task(POST)
• Store data in SQLite database 
• JSON response 
• REST API using Flask
🛠️ Technologies Used 
• Python 
• Flask 
• SQLite
• JSON
