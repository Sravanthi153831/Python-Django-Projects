# Logistics Order Management API

A simple backend API built using **Python Flask** and **SQLite** to manage and track logistics orders.

## 🚀 Features

- Secure user authentication
- SQLite database integration
- Create and manage orders
- Fetch active orders
- Track delivery status
- Track current order location
- JSON API responses

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- REST API
- JSON
