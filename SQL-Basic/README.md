Smart E-Commerce Order Tracking System

A clean and production-ready Python application integrated with SQLite3 database architecture, demonstrating advanced Object-Oriented Programming (OOP) and live data persistence.

## 🚀 Core Technical Capabilities
- **Object-Oriented Design**: Utilizes robust encapsulation to manage real-world e-commerce entities.
- **Data Persistence**: Integrates raw `sqlite3` to perform direct database executions without heavy ORM overhead.
- **State Management**: Implements an advanced SQL `UPDATE` method to dynamically update live order shipping statuses from 'Processing' to 'Shipped'.

## 🛠️ Technology Stack
- **Language**: Python 3.x
- **Database**: SQLite3
- **Environment**: Mobile Terminal Execution Verified
